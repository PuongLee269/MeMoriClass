## Trạng thái Bọ cần cho trang (quản lý chốt)
| Trạng thái | Khi nào dùng trên trang |
|---|---|
| Đứng yên thở nhẹ (idle) | Mặc định, chờ người dùng |
| Chào (vẫy chân) | Vừa mở trang |
| Đang nói | Khung thoại đang hiện câu trả lời |
| Lắng nghe | Người dùng đang gõ vào ô hỏi |
| Suy nghĩ | Đang chờ AI trả lời |
| Vui / cười tít mắt | Trả lời xong, người dùng cảm ơn |
| Ngạc nhiên | Câu hỏi lạ, sự kiện mới |
| Bối rối / xin lỗi | Lỗi mạng, không hiểu câu hỏi |
| Chỉ đường | Chỉ sang bản đồ / nút "Tham quan bản đồ" |
| Buồn ngủ / ngủ gật | Để lâu không tương tác |
| Mở cánh, cất cánh, bay | Chuyển sang trang bản đồ |
