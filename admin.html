Cách tạo token GitHub (làm một lần, mất khoảng 2 phút)
  1. Đăng nhập GitHub bằng tài khoản chủ kho mã, mở github.com/settings/personal-access-tokens/new (Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token).
  2. Token name: ví dụ memori-admin. Expiration: chọn 30 hoặc 90 ngày (đừng chọn “No expiration”).
  3. Repository access: chọn Only select repositories rồi chọn duy nhất kho MemoriClass.
  4. Permissions → Repository permissions → Contents: chọn Read and write. Không cần cấp quyền nào khác (Metadata: Read-only tự có).
  5. Bấm Generate token, sao chép chuỗi bắt đầu bằng github_pat_ và dán vào ô bên dưới. GitHub chỉ hiện chuỗi này một lần.

Token chỉ lưu trong trình duyệt này (localStorage) và chỉ được gửi tới api.github.com. Bấm Đăng xuất là xóa. Nếu nghi lộ token: vào GitHub → Settings → Fine-grained tokens → Revoke.

Trang này công khai nhưng không chứa bí mật nào và không thể thay đổi gì nếu thiếu token hợp lệ.
